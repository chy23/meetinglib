# 📚 會議資料庫 - 教師午會圖書館

網址：https://chy23.github.io/meetinglib/ （公開免登入，支援手機與電腦）

提供像圖書館一樣查閱、全文檢索、AI 核心速覽與高速閱讀學校會議紀錄的現代化網站。

---

## 🌟 重點功能特色

1. **⚡ 純文字速讀模式（瞬開 0 秒）**
   - 解決以往 PDF 載入慢、檔案大的問題，開啟立即閱讀，手機觀看特別省流量。
   - 自動將公文段落格式化排版，標題大字、處室明顯，文字可隨意反白與複製。
   - 提供頂部 `A-` / `A+` 字體大小縮放調節。
2. **📑 原始 PDF 模式（原圖完整呈現）**
   - 採用 PDF.js 視窗懶加載（Lazy Loading），捲到該頁才繪製，記憶體極低且滑動流暢。
   - 完整保留簽呈、章戳與彩色照片。
3. **📁 學年度與學期階層式目錄**
   - 自動辨識「115學年度 第一學期」等分組，支援折疊收合。
   - 每個項目清晰標示週次（如：第九週）與各處室出現在本篇的彩色徽章。
4. **🔗 本次會議之各項連結與表單**
   - 自動提取該場會議提及之各項線上表單（Google Forms）、線上會議（Google Meet）、雲端硬碟、研習平台與宣導影音，提供一鍵複製與直接開啟。
5. **📍 處室快速跳轉與快篩**
   - 文章頂部附帶該篇涉及處室標籤，點擊直接平滑滾動到該處室段落。
   - 側邊欄上方提供處室快篩膠囊（教務處、學務處、總務處、輔導處），一鍵過濾特定處室的會議。
6. **🔗 網址自動錨定（Deep Link）**
   - 瀏覽器網址列自動同步會議日期錨點（如 `#2026-10-28`），複製網址傳給同仁點開直接抵達該場會議。
7. **🔍 全文搜尋強化（支援 `⌘K` / `Ctrl+K`）**
   - 包含前後文情境預覽（Snippets）與關鍵字黃底高亮，點選直接跳入對應段落。
8. **📥 一鍵下載 PDF 與 🖨️ 列印最佳化**
   - 提供原始 PDF 快速下載。
   - 列印時自動去除導航列與按鈕，輸出乾淨紙本紀錄。

## 📅 每週維護與極速發布（兩種方式任選）

### 方式一：🖥️ macOS 桌面狀態列發布小秘書（極速 30 秒雙站發布）
1. 在 Mac 右上角狀態列點選「📚」，選擇「📤 拖曳／選取會議 PDF 發布...」。
2. 直接把 PDF 拖進懸浮視窗，點擊「🚀 一鍵發布與推播部署」。
3. 系統將於 30 秒內自動完成：
   - 同步存入本機 **Google 雲端硬碟** (`~/Google 雲端硬碟/會議資料`)
   - 提取全文、相片，並執行**學生個資去識別化脫敏**
   - 推送至 **GitHub Pages**，網站自動部署更新
   - macOS 系統即時跳出橫幅推播通知！

### 方式二：☁️ 雲端全自動同步（免開電腦）
1. 將新的 PDF 放進 Google 雲端資料夾，檔名維持：`YYYY-MM-DD_標題.pdf`（例如 `2026-11-04_教師午會記錄.pdf`）。
2. Google Apps Script 與 GitHub Actions 每小時定時自動爬取與同步上線。

## 🛠️ 技術架構
- **前端展示**：GitHub Pages 靜態網站（`index.html`，純前端、無伺服器負擔、反應極速）。
- **後端自動化**：Google Apps Script（OCR 文字擷取與定時觸發）。
- **同步與摘要處理**：GitHub Actions（`scripts/sync.py` + `.github/workflows/sync.yml` 每小時排程）。
